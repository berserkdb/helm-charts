{{- if .Values.gateway.enabled }}

To set up the initial admin user, grab the one-time bootstrap URL from
the gateway logs and open it in a browser:

  kubectl -n {{ .Release.Namespace }} logs deploy/gateway | grep -A2 "Initial admin setup"
{{- end }}

Every sender presents an ingest token of its own. Once signed in, create a
table and a token for it, on the Settings page or with the bzrk CLI:

  bzrk table create default
  bzrk ingest-token create --table default my-ingest-token

Query, nursery and janitor keep unencrypted copies of your telemetry on local
disk. Encrypt those volumes (encrypted storageClass, node disks or dm-crypt);
Berserk does not encrypt them itself.

Check pod status:
  kubectl get pods -n {{ .Release.Namespace }}
