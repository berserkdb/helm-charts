{{- if .Values.global.ingestToken.enabled }}

Data sent from inside the cluster without a bearer lands in the "{{ .Values.global.defaultTable }}"
table under the default ingest token, which meta derives from the master key and
registers at startup. That token never leaves the cluster; set
`global.ingestToken.enabled=false` on an endpoint that must refuse anonymous data.
{{- end }}

Every other sender gets its own token. To create one for the "{{ .Values.global.defaultTable }}" table:
  kubectl run bzrk-cli -n {{ .Release.Namespace }} --image={{ $cliImage }} --labels=app=admin,app.kubernetes.io/instance={{ .Release.Name }} --command -- sleep 3600
  kubectl wait --for=condition=Ready pod/bzrk-cli -n {{ .Release.Namespace }}
  kubectl exec -it bzrk-cli -n {{ .Release.Namespace }} -- /cli --meta-endpoint meta:{{ .Values.meta.service.port }} table create --if-not-exists {{ .Values.global.defaultTable }}
  kubectl exec -it bzrk-cli -n {{ .Release.Namespace }} -- /cli --meta-endpoint meta:{{ .Values.meta.service.port }} ingest-token create --table {{ .Values.global.defaultTable }} my-ingest-token
  kubectl delete pod bzrk-cli -n {{ .Release.Namespace }}
